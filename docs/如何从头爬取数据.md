# 如何从头开始爬取数据

本指南将帮助您从零开始爬取毕业设计题目数据。

## 📋 准备工作

### 1. 确保数据库已初始化

首先确保数据库已经正确设置：

```bash
# 1. 生成 Prisma 客户端
npm run db:generate

# 2. 推送数据库结构（如果还没创建表）
npm run db:push

# 3. （可选）查看数据库状态
npm run db:studio
```

### 2. 检查环境变量

确保 `.env.local` 文件中的数据库连接正确：

```env
DATABASE_URL="file:./dev.db"
NODE_ENV=development
```

## 🚀 开始爬取数据

### 方式一：使用默认爬虫脚本（推荐）

项目已经配置好了爬虫脚本，直接运行即可：

```bash
npm run crawler
```

这个命令会：

- 自动启动无限爬取模式
- 使用高性能配置（并发4，批量100）
- 自动保存数据到数据库
- 自动处理重复数据
- 连续3页无数据时自动停止

### 方式二：自定义爬取配置

如果您想自定义爬取参数，可以修改 `scripts/crawler.ts` 文件：

```typescript
const crawler = new ChaoxingCrawler({
  concurrency: 4, // 并发数量（建议2-5）
  batchSize: 100, // 批量保存大小（建议50-200）
  delay: 400, // 请求延迟（毫秒，建议400-2000）
  retryAttempts: 5, // 重试次数
  adaptiveDelay: true, // 启用自适应延迟（推荐）
  pageSize: 5000, // 每页数据量（API限制）
});
```

### 方式三：爬取指定页数

如果您只想爬取前几页测试，可以创建自定义脚本：

```typescript
// scripts/custom-crawler.ts
import { ChaoxingCrawler } from '../src/lib/crawler';

async function main() {
  const crawler = new ChaoxingCrawler({
    maxPages: 10, // 只爬取10页
    delay: 1000, // 每页延迟1秒
  });

  const result = await crawler.crawlAllPages(10);
  console.log('爬取完成:', result);
}

main();
```

然后运行：

```bash
npx tsx scripts/custom-crawler.ts
```

## ⚙️ 爬虫配置参数说明

### 性能参数

| 参数          | 说明         | 推荐值     | 说明                           |
| ------------- | ------------ | ---------- | ------------------------------ |
| `concurrency` | 并发数量     | 3-4        | 同时爬取的页面数，过高可能被封 |
| `batchSize`   | 批量保存大小 | 50-100     | 每次保存到数据库的数据量       |
| `delay`       | 请求延迟     | 400-2000ms | 请求间隔，避免被封             |
| `pageSize`    | 每页数据量   | 5000       | API返回的数据量                |

### 可靠性参数

| 参数            | 说明       | 推荐值 |
| --------------- | ---------- | ------ |
| `retryAttempts` | 重试次数   | 3-5    |
| `adaptiveDelay` | 自适应延迟 | `true` |

### 限制参数

| 参数       | 说明         | 推荐值 |
| ---------- | ------------ | ------ |
| `maxPages` | 最大爬取页数 | 50-500 |

## 🛑 停止爬取

爬虫会自动在以下情况停止：

1. **连续3页无数据** - 说明已经爬完所有数据
2. **手动中断** - 按 `Ctrl+C` 优雅退出，已保存的数据不会丢失

## 🔍 查看爬取的数据

爬取完成后，您可以通过以下方式查看数据：

### 1. 使用 Prisma Studio（推荐）

```bash
npm run db:studio
```

这将打开浏览器界面，您可以可视化查看和编辑数据。

### 2. 导出数据

```bash
npm run data:export
```

这会将数据库中的数据导出到 `data/exports/` 目录。

## 🎯 最佳实践

### 1. 首次爬取建议

- ✅ 先用小页数测试（如5-10页）
- ✅ 确认数据格式和内容正确
- ✅ 检查数据库保存是否正常

### 2. 大规模爬取建议

- ✅ 使用较长的延迟（1000-2000ms）避免被封
- ✅ 分批进行，不要一次性爬取太多
- ✅ 定期检查数据质量
- ✅ 保存爬取日志，方便排查问题

### 3. 避免被封的策略

- ⚠️ 不要设置过高的并发数（建议≤5）
- ⚠️ 设置合理的延迟（建议≥400ms）
- ⚠️ 启用自适应延迟
- ⚠️ 不要在高峰期大量爬取
- ⚠️ 如果被封，等待一段时间后重试

## 🐛 常见问题

### 1. 网络连接错误

**错误信息**:

```
Error: connect ECONNREFUSED
```

**解决方法**:

- 检查网络连接
- 检查API地址是否正确
- 稍后重试

### 2. 数据库连接错误

**错误信息**:

```
Error: Can't reach database server
```

**解决方法**:

- 检查 `.env.local` 中的 `DATABASE_URL`
- 确保数据库文件存在且有读写权限
- 运行 `npm run db:push` 初始化数据库

### 3. 数据保存失败

**错误信息**:

```
保存数据失败: [标题]
```

**解决方法**:

- 检查数据格式是否正确
- 查看数据库日志
- 检查是否有唯一约束冲突

### 4. 爬取速度慢

**优化建议**:

- 适当增加并发数（但不要超过5）
- 减少延迟时间（但不要低于400ms）
- 增加批量保存大小

## 📝 下一步

爬取完数据后，建议：

1. **训练模型**: `npm run train` - 基于爬取的数据训练马尔科夫链模型
2. **导入预置数据**: `npm run data:import` - 如果还想使用项目预置的数据
3. **开始使用**: `npm run dev` - 启动应用，开始生成选题
