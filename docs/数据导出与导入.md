# 数据导出与导入

本指南将帮助您管理 TopicForge 的数据，包括导出备份和导入恢复。

## 📋 快速开始

```bash
# 导出数据库数据
npm run data:export

# 导入样例数据（1,000 条）
npm run data:import

# 导入完整数据（全量）
npm run data:import:full

# 强制导入（覆盖现有数据）
npm run data:import:force
```

## 📤 数据导出

### 运行导出命令

```bash
npm run data:export
```

该命令会将数据库中的数据导出到两个目录：

| 目录            | 说明                               |
| --------------- | ---------------------------------- |
| `data/exports/` | 完整数据（全量导出）               |
| `data/seeds/`   | 种子数据（采样版，用于快速初始化） |

### 导出的文件

| 文件名                          | 说明                           | 位置    |
| ------------------------------- | ------------------------------ | ------- |
| `graduation-topics.json`        | 所有毕业设计题目               | exports |
| `graduation-topics-sample.json` | 前 1,000 条样本                | seeds   |
| `majors.json`                   | 专业数据                       | 两者    |
| `keyword-stats.json`            | 关键词统计（前 5,000 条）      | 两者    |
| `markov-chains.json`            | 马尔可夫链（前 10,000 条）     | 两者    |
| `major-markov-chains.json`      | 专业马尔可夫链（前 10,000 条） | 两者    |
| `generated-topics.json`         | 生成的题目样例（最近 100 条）  | exports |
| `metadata.json`                 | 导出元数据（时间、版本、统计） | 两者    |
| `topicforge-data.sql`           | SQL 格式导出                   | exports |

## 📥 数据导入

### 导入样例数据

用于快速初始化开发环境，导入前 1,000 条样本数据：

```bash
npm run data:import
```

### 导入完整数据

导入全部数据（如果 `graduation-topics.json` 存在）：

```bash
npm run data:import:full
```

### 强制覆盖导入

如果数据库中已有数据，需要使用 `--force` 参数强制导入：

```bash
npm run data:import:force
```

### 导入参数说明

| 参数      | 命令                        | 说明                                             |
| --------- | --------------------------- | ------------------------------------------------ |
| 默认      | `npm run data:import`       | 导入 `graduation-topics-sample.json`（1,000 条） |
| `--full`  | `npm run data:import:full`  | 导入 `graduation-topics.json`（全量）            |
| `--force` | `npm run data:import:force` | 强制覆盖现有数据                                 |

### 导入顺序

导入脚本会按以下顺序处理数据：

1. **专业数据** (Majors) - 逐个插入，跳过重复
2. **毕业设计题目** (GraduationTopics) - 逐个插入，显示进度
3. **关键词统计** (KeywordStats) - 批量导入
4. **马尔可夫链** (MarkovChains) - 批量导入
5. **专业马尔可夫链** (MajorMarkovChains) - 逐个插入
6. **生成的题目** (GeneratedTopics) - 逐个插入

## 🎯 使用场景

### 场景 1：开发环境初始化

新克隆项目后，快速初始化开发环境：

```bash
# 1. 安装依赖
npm install

# 2. 初始化数据库
npm run db:generate
npm run db:push

# 3. 导入样例数据
npm run data:import
```

### 场景 2：数据备份

定期备份生产数据：

```bash
# 导出当前数据库
npm run data:export

# 备份文件会保存在 data/exports/ 目录
# 建议将此目录加入版本控制或单独备份
```

### 场景 3：数据恢复

从备份恢复数据：

```bash
# 确保 data/seeds/ 目录有导出的数据文件

# 强制导入（会覆盖现有数据）
npm run data:import:force
```

### 场景 4：环境迁移

将开发环境的数据迁移到生产环境：

```bash
# 在开发环境导出
npm run data:export

# 将 data/exports/ 目录复制到生产环境

# 在生产环境导入
npm run data:import:full --force
```

### 场景 5：爬取数据后导出

爬取完数据后保存种子文件：

```bash
# 1. 运行爬虫
npm run crawler

# 2. 训练模型（可选）
npm run train

# 3. 导出数据
npm run data:export

# 数据文件会保存在 data/ 目录下
```

## ⚠️ 注意事项

### 导出注意

- ❌ **会话数据不会导出** - `generation_sessions` 表是临时数据，不包含在导出中
- ⚠️ 导出会覆盖之前的导出文件
- ✅ SQL 导出文件可用于其他数据库系统

### 导入注意

- ⚠️ 导入前请确保数据库结构已创建：`npm run db:push`
- ⚠️ 如果数据库已有数据，需要使用 `--force` 参数
- ⚠️ 导入会自动跳过重复数据（基于唯一约束）
- ✅ 导入过程会显示实时进度

### 文件大小参考

| 数据量        | 文件大小（约） |
| ------------- | -------------- |
| 1,000 条题目  | ~0.45 MB       |
| 10,000 条题目 | ~4.5 MB        |
| 25,000 条题目 | ~11 MB         |

## 🐛 常见问题

### 1. 导入时提示"数据库中已存在数据"

```
⚠️  数据库中已存在 1000 条毕业设计题目数据
使用 --force 参数强制导入，或先清空数据库
```

**解决方法**：使用 `npm run data:import:force` 强制导入

### 2. 找不到种子文件

```
Error: ENOENT: no such file or directory
```

**解决方法**：

- 确保 `data/seeds/` 目录存在
- 先运行 `npm run data:export` 导出数据
- 或从备份恢复 `data/seeds/` 目录

### 3. 数据库未初始化

```
Error: Can't reach database server
```

**解决方法**：

```bash
npm run db:generate
npm run db:push
```

### 4. 导入进度很慢

大量数据导入时可能较慢，这是正常现象。进度会每 1,000 条显示一次：

```
进度: 5000/25000 条 (20.00%)
```

## 📁 目录结构

导出完成后，`data/` 目录结构如下：

```
data/
├── exports/                        # 完整导出数据
│   ├── graduation-topics.json      # 所有题目
│   ├── majors.json                 # 专业数据
│   ├── keyword-stats.json          # 关键词统计
│   ├── markov-chains.json          # 马尔可夫链
│   ├── major-markov-chains.json    # 专业马尔可夫链
│   ├── generated-topics.json       # 生成的题目
│   ├── metadata.json               # 元数据
│   └── topicforge-data.sql         # SQL 导出
└── seeds/                          # 种子数据
    ├── graduation-topics-sample.json  # 样本数据（1,000条）
    ├── majors.json
    ├── keyword-stats.json
    ├── markov-chains.json
    ├── major-markov-chains.json
    └── metadata.json
```
